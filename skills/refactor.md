# リファクタリング

このSkillはコードのリファクタリングを行い、品質を改善します。

## リファクタリングの原則

- **動作の保持**: リファクタリング後も既存のテストがすべてパスすること
- **段階的な変更**: 一度に大きな変更をせず、小さなステップで進める
- **テストファースト**: リファクタリング前にテストが存在しない場合は先にテストを作成する

## 主なリファクタリング手法

### コードの整理
- **Extract Method**: 長いメソッドを小さな関数に分割する
- **Extract Class**: 責務が多すぎるクラスを分割する
- **Rename Variable/Function**: より意味が明確な名前に変更する
- **Remove Dead Code**: 使われていないコードを削除する

### 重複の排除
- **Extract Common Logic**: 重複したコードを共通関数に切り出す
- **Template Method Pattern**: 似た処理の共通部分を親クラスにまとめる
- **Strategy Pattern**: 条件分岐をポリモーフィズムで置き換える

### 構造の改善
- **Replace Magic Numbers**: マジックナンバーを定数に置き換える
- **Simplify Conditional**: 複雑な条件式を簡素化する
- **Replace Nested Loops**: ネストしたループをより読みやすい形に変換する
- **Early Return**: ネストを減らすために早期リターンを活用する

### 現代的な書き方への移行
- 言語の最新機能（async/await、型ヒント、パターンマッチなど）を活用する
- イディオマティックなコードスタイルに合わせる

## 使い方

```
以下のコードをリファクタリングしてください：
<コードを貼り付け>
```
