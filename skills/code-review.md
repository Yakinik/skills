# コードレビュー

このSkillはコードレビューを実施し、以下の観点から評価・フィードバックを提供します。

## レビューの観点

### 1. コード品質
- 変数・関数・クラスの命名が適切か
- 単一責任の原則（SRP）に従っているか
- DRY原則（Don't Repeat Yourself）が守られているか
- 適切なエラーハンドリングが実装されているか

### 2. セキュリティ
- SQLインジェクション・XSSなどの脆弱性がないか
- 入力値のバリデーションが適切に行われているか
- 機密情報（APIキー・パスワードなど）がハードコードされていないか
- 認証・認可のロジックが正しいか

### 3. 可読性・保守性
- コードが読みやすく理解しやすいか
- 適切なコメントやドキュメントが付いているか
- 複雑なロジックが適切に分割されているか

### 4. パフォーマンス
- 不必要な計算やループがないか
- 適切なデータ構造やアルゴリズムが使われているか
- N+1問題などのパフォーマンスアンチパターンがないか

### 5. テスト
- 適切なユニットテスト・統合テストが存在するか
- エッジケースがテストされているか
- テストカバレッジが十分か

## フィードバックの形式

レビュー結果は以下の重大度で分類します：

- 🔴 **Critical**: セキュリティ上の脆弱性やバグなど、必ず修正が必要な問題
- 🟡 **Warning**: 品質やパフォーマンスに影響する問題で、修正を強く推奨
- 🔵 **Info**: 可読性や保守性の向上のための提案
- ✅ **Good**: 良い実装として特記すべき箇所

## 使い方

```
このコードをレビューしてください：
<コードを貼り付け>
```

または特定の観点を指定することもできます：

```
セキュリティの観点でこのコードをレビューしてください：
<コードを貼り付け>
```
