# テスト作成

このSkillは既存のコードに対してユニットテストを作成します。

## 対応テストフレームワーク

| 言語 | フレームワーク |
|------|--------------|
| Python | pytest, unittest |
| JavaScript / TypeScript | Jest, Vitest, Mocha |
| Java | JUnit 5, Mockito |
| Go | testing パッケージ |
| Ruby | RSpec, Minitest |
| C# | xUnit, NUnit, MSTest |

## テスト作成の手順

1. **対象コードの分析**
   - 関数・メソッドの入出力を確認する
   - 依存関係（外部サービス、DB など）を把握する
   - エラーケースや境界値を特定する

2. **テストケースの設計**
   - 正常系（Happy Path）のテスト
   - 異常系・エラーケースのテスト
   - 境界値のテスト
   - エッジケースのテスト

3. **テストの実装**
   - AAA パターン（Arrange / Act / Assert）に従う
   - テスト名は「何をテストするか」が明確になるよう命名する
   - モック・スタブを使って外部依存を分離する

## テストの品質指標

- **カバレッジ**: 行カバレッジ 80% 以上を目指す
- **独立性**: 各テストは他のテストに依存しない
- **再現性**: 何度実行しても同じ結果になる
- **可読性**: テストコード自体がドキュメントとして機能する

## 使い方

```
以下のコードのテストを書いてください：
<コードを貼り付け>
```

フレームワークを指定することもできます：

```
pytest を使って以下のコードのテストを書いてください：
<コードを貼り付け>
```
